
## Annotation Schema (Quick Reference)

### 1. Sentence Difficulty (1-5, SOURCE-ONLY)
- 1 = Trivial
- 2 = Easy
- 3 = Moderate
- 4 = Difficult
- 5 = Very Difficult

### 2. Linguistic Phenomena (6 binary tags)
- ambiguity
- idiom
- complex_syntax
- named_entities
- figurative_language
- long_distance_dependency

### 3. Trace Type (5 categories)
- CORRECT_LINGUISTIC_ANALYSIS
- HALLUCINATED_RULE
- VACUOUS_FILLER
- TRANSLATION_ATTEMPT
- REPETITION

### 4. Trace Usefulness
- helpful
- neutral
- harmful

### 5. Trace-Translation Overlap
- none (<5%)
- low (5-25%)
- medium (25-75%)
- high (>75%)

## Troubleshooting Guide

### "Out of memory" during evaluation
```bash
# Reduce batch size
--request_batch_size 1
```

### "CUDA out of memory" during annotation
```bash
# Use CPU or reduce batch size
--batch_size 1
```

### "Parse errors" in LLM annotation
- Check `llm_annotations_full_raw.jsonl` to see what LLM generated
- LLM might not be following JSON format
- Try different model or adjust prompt

### Evaluation is too slow
- Reduce `--max_samples` to 10 for testing
- Use smaller model (`google/gemma-2-2b-it`)
